# Friday Night Funkin' - NotePulse Engine

This engine is a WIP fork of Psych Engine v0.7.3, made with the purpose of giving modders tool that make coding a lot easier, adding equivalents of tools other Friday Night Funkin' engines have.

You can find the differences [docs/Diffs.md]
And some help at modding [here](docs/LUA.md)

## Where to download?
You can just download a [release](https://github.com/Manganosl/NotePulse-Engine/releases).
Or you can simply try an [actions build](https://github.com/Manganosl/NotePulse-Engine/actions) and hope nothing breaks. Of course, these builds can have lots of errors and unfinished things (although even the releases have unfinished things)

## How to compile?
You'll find everything needed in the [setup](setup) folder. Just make sure to have Haxe installed!
(Windows Only) If you dont have Visual Studio, run [setup-msvc-win.bat](setup/setup-msvc-win.bat).
If you need the libraries, run [setup-windows.bat](setup/setup-windows.bat) or [setup-unix.sh](setup/setup-unix.sh).

Then you can just compile!
